# Portfolio

> Just my portfolio website. Nothing too much... or is it?

## 🛠️ Tech Stack

- **Core:** React, TypeScript, Vite, Tailwind CSS v4
- **Animation & 3D:** Motion, React Globe.gl
- **Tooling:** Oxlint

## 📦 Local Development

Clone the project and install dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

Build and optimize for production:
```bash
npm run build
```
